# SEO Blueprint

## Objective

Earn qualified organic visits by publishing genuinely useful, trustworthy pages that match a specific question or task. Rankings are an outcome, not a reason to dilute compliance or editorial quality.

## Keyword-to-content process

1. Identify a real user question, task, or comparison need.
2. Group it with close variants that deserve one comprehensive answer.
3. Classify intent: learn, solve, prepare, evaluate, or contact.
4. Choose the correct template and hub.
5. Check that the planned answer can be stated accurately and approved.
6. Create the page brief, then write for the reader—not the keyword count.

## Priority clusters for launch

| Cluster                       | Intent examples                                   | Format                           |
| ----------------------------- | ------------------------------------------------- | -------------------------------- |
| Everyday wellness habits      | building consistent routines, balanced meals      | Guides + hub                     |
| Practical nutrition education | breakfast ideas, hydration habits, protein basics | Guides + FAQs                    |
| Recipes and preparation       | simple meal ideas, ingredient preparation         | Recipes                          |
| Wellness terminology          | clear definitions                                 | Glossary + internal links        |
| Brand/product questions       | approved factual information only                 | Restricted, approval-gated pages |
| Business questions            | approved factual opportunity information only     | Restricted, approval-gated pages |

## Technical baseline

- Render crawlable HTML with one canonical URL per page.
- Generate XML sitemaps only for indexable, published, reviewed pages.
- Use robots controls deliberately: block internal search results, draft previews, and private routes from indexing.
- Return correct HTTP statuses; keep redirect mappings for moved public URLs.
- Optimize images, minimize scripts, and measure Core Web Vitals on real mobile conditions.
- Provide descriptive title, meta description, heading hierarchy, alt text, and internal links for each page.
- Add structured data only when it mirrors visible content and meets search-engine rules.

## Content quality controls

- One primary intent per URL; consolidate duplicates.
- Put the direct, qualified answer near the top.
- Include context, limits, sources, and a review date where warranted.
- Do not generate thin city/keyword variations, scraped summaries, fake reviews, or unverified comparisons.
- Do not use health or earnings language merely because it attracts searches.

## Measurement

Track index coverage, impressions, clicks, queries, landing-page engagement, internal search refinements, contact-request completion, accessibility issues, and performance. Analyze at the cluster level, then improve usefulness—not just wording.

## Pre-publish SEO check

- [ ] Search intent and audience are recorded.
- [ ] The page offers a distinct, complete answer.
- [ ] Title, description, heading, URL, and canonical match the actual content.
- [ ] Internal links are useful and destination labels are descriptive.
- [ ] Claims, assets, and disclosures have cleared review.
- [ ] Mobile performance and accessibility checks pass.
- [ ] Indexing eligibility is deliberate.
