# WelliQo Content Constitution

## 1. Editorial promise

We make wellness information easier to understand without exaggerating outcomes or disguising marketing as education. Content must be useful on its own, even if a reader never contacts anyone.

## 2. Voice

Clear, warm, practical, and honest. Use everyday language, short paragraphs, and concrete next steps. Avoid hype, fear, shame, medical authority, and pressure. Say what is known, what varies, and when professional advice is appropriate.

## 3. Page anatomy

Every indexable educational page should contain:

1. Search-intent-aligned title and introduction.
2. Direct answer or useful summary near the top.
3. Scannable, sourced main sections.
4. Safety/context note where health, products, or individual suitability is discussed.
5. Related internal links chosen for relevance.
6. One proportional next step—read, save, compare approved information, or request contact.
7. Author/owner, last reviewed date, and sources where appropriate.

## 4. Required metadata

| Field           | Rule                                                       |
| --------------- | ---------------------------------------------------------- |
| URL             | Short, descriptive, lowercase, stable                      |
| Title           | Accurate, specific, intent-led; no clickbait               |
| Description     | Plain-language value statement; no unverified result claim |
| Canonical       | One approved canonical URL per page                        |
| Social preview  | Approved visual and neutral, accurate copy                 |
| Structured data | Only schema matching visible content and eligibility rules |
| Review date     | Required for all editorial content                         |

## 5. Content types

**Guide:** education around a single visitor question.  
**FAQ:** concise, direct answer; never use it to hide material qualifications.  
**Recipe:** ingredients, steps, servings, and a clear source/approval record for nutrition statements.  
**Product education:** only approved market content; no implied health result.  
**Business information:** factual, approval-gated, with required earnings context.  
**Story/testimonial:** exceptional review path; no outcome implication without written approval.  
**Tool result:** educational only, explains limits, avoids diagnosis/prescription, and gives safety signposting.

## 6. Sources and claims

- Keep a claim-to-source record for every material factual statement.
- Prefer primary, authoritative, current sources and market-approved materials.
- Attribute sources appropriately; do not copy copyrighted text or imagery without permission.
- A source does not by itself authorize an Herbalife, product, business, or health claim—approval is still required.
- Remove or revise content when a source, policy, product detail, or regulation changes.

## 7. Calls to action

CTAs must match the page intent and be optional. Good: “Explore related guides”, “Save this recipe”, “Request a conversation”. Not allowed: urgency, false scarcity, outcome promises, disguised ads, or confusing contact consent.

## 8. SEO and internal linking

Create one substantial page per intent. Avoid keyword stuffing, doorway pages, spun variants, copied supplier text, and irrelevant links. Link where it helps the reader continue learning; every link label must describe its destination.

## 9. Accessibility and media

Use meaningful headings, descriptive link labels, captions/transcripts where needed, text alternatives for informative images, and sufficient color contrast. All visual assets need source, license/approval, alt text, and review status.

## 10. Workflow

`Brief → research → draft → source check → compliance/brand/privacy review as needed → publish → monitor → scheduled review`

The content record must include owner, content type, intended market, sources, approvals, publish date, review date, and change log. Urgent corrections take priority over editorial calendars.
